# 工具包框架
框架实现的功能：
1. 不用自己动手构造tools参数
2. 基于面向对象的思想把单个工具封装为类进行统一管理
3. 自动导入工具及其映射的方法统一自动导入

在tools_manage包定义工具，别处可能叫插件吧
这里不仅仅是为了未来的双Agent做处理，也是为了方便扩展做处理。

工具包，插件在这个包下开发，官方说最对128个工具，但是只要工具中进行二级提问(双Agent)能实现无数量限制的工具定义
```bash
tools_manage/
├── __init__.py
├── base_tool.py
└── tools_register.py
```
初始化文件：`__init__.py`
工具定义的基类：`base_tool.py`
工具注册文件：`tools_register.py`
每次导入tools_manage这个包时会自动调用`tools_register.py`这个文件执行代码生成`tools`和`tools_map`，工具参数和映射的工具地址。

# 插件撰写
有一点需要注意，使用工具时使用的不是R1模型，也就是没有推理功能。所以`self.reasoning_content += chunk.choices[0].delta.reasoning_content or "" # 累积推理过程`会直接报错

工具间会有冲突，所以需要对相类似的工具做区分或直接整合
## 时间插件
`get_current_time_and_calendar_info.py`
获取现在的年份, 月份, 日期, 小时, 分钟, 秒钟, 毫秒, 星期几, 星期, 秒级时间戳, 毫秒级时间戳,
公历日期, 农历日期, 农历年, 农历月, 农历日, 生肖, 天干地支, 是否为节假日, 节日名称, 是否为国际性节日, 二十四节气

## 图片插件
### 下载特定主题图片
`download_images_for_a_specific_topic.py`
沿袭了之前的图片发送指令，从用户自定义的api中抽取主题发送指定数量的图片
配置文件：`爱丽丝QQ聊天AI/用户设置/关键词回复/图片映射表.json`

### 从图片引擎中搜索下载图片
搜索引擎：亿图全景图库
API端点：https://www.yeitu.com/
通过1个关键词下载并发送指定数量的图片
本质就是爬虫（深度爬虫），这个是高效且低功耗的（仅仅`requests` + `re`）
